# План разработки Glow Path Defense

Дата: 19 октября 2026 года. Основание: [справка о текущей игре](GAME_STATE.md).

Предлагаемая ближайшая цель: законченный и проверенный уровень с 5 волнами, тремя понятными башнями и тремя типами врагов. Число волн и состав контента — рабочее предложение для планирования, не ранее утверждённый дизайн. Сроки без выбора платформы и игрового прогона не оценивались.

Приоритеты: **P0** — стабильность основы; **P1** — законченный игровой уровень; **P2** — расширение после проверки уровня. Зависимости указаны по ID. Все задачи открыты; данный аудит ничего из списка не реализует.

## Порядок ближайшей работы

1. Зафиксировать платформу и исходное состояние: DEV-01–03.
2. Исправить завершение боя, UI, покупку, выбор целей и работу пула: DEV-04–09.
3. Проверить существующий прототип: DEV-10. По результатам уточнить список дефектов.
4. Утвердить роли башен, сделать серию волн, новые типы врагов и баланс: DEV-11–15.
5. Довести понятность, ввод, звук и сборку; провести плейтест: DEV-16–23.

Критерий завершения ближайшего этапа разработки: новый игрок самостоятельно проходит полный уровень из 5 волн, понимает различия башен, может проиграть и начать заново; результат воспроизводится в целевой сборке без блокирующих ошибок. Следующие карты, кампания и дополнительные системы добавляются после этой проверки.
