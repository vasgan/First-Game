# Настройка волн

Параметры находятся в `Assets/Game/Data/WaveConfig.asset` (Inspector Unity).

- `Enemy Count`, `Spawn Interval`, `Completion Reward` — параметры по умолчанию.
- `Waves` — необязательный список настроек: элемент 0 соответствует первой волне, элемент 1 — второй и т. д. Для волн после конца списка используются параметры по умолчанию.
- Каждый элемент задаёт количество врагов, интервал появления, награду, `Health Multiplier`, а также `Enemy Config` и `Enemy Prefab`. Пустые ссылки используют тип врага, указанный в WaveController. Для разных внешних видов укажите соответствующие prefab.
- `Test Health Growth Percent` — прирост здоровья между волнами в Test Profile; сейчас 7%.

Здоровье рассчитывается как `EnemyConfig.maxHealth × HealthMultiplier × 1.07^(номер волны − 1)` в тестовом режиме; в обычном профиле множитель прогрессии отсутствует. Результат округляется до ближайшего целого только после расчёта (минимум 1 HP, максимум int.MaxValue). При базовых 100 HP первые волны получают 100, 107, 114, 123, 131 HP. Общий EnemyConfig не изменяется. Полоска здоровья использует максимум конкретного врага, включая повторное появление из пула.

Сейчас обычный профиль по-прежнему заканчивается после одной волны. Тестовый профиль запускает следующие волны через 5 секунд. Список настроек сам по себе не меняет условия победы.

Проверка в Unity: меню `First Game → Validate Waves`. Проверяет рост HP, обычный профиль, параметры отдельных волн, возврат к значениям по умолчанию, защиту от переполнения и применение здоровья к экземпляру prefab.
